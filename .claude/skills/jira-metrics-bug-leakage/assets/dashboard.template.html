How this is measured

Leakage is read off one field, so it is exactly as reliable as that field.

  • A defect counts as escaped when its {{phaseFieldName}} is Production, and as caught when it is Development. Leakage is escaped ÷ classified; containment is its complement.
  • This measures where a defect was found, not where it was introduced. A defect written a year ago and reported by a user today counts against today.
  • The field is set by hand. A falling leakage rate can mean testing improved — or that nobody is setting the field on production reports. Read it alongside the count of unclassified defects.
  • Severity-weighted leakage applies the priority weights {{weightSummary}}, because one escaped Highest is not the same event as one escaped Low.
